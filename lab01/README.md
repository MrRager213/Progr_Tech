## Цель работы

Освоить базовые операции работы с системой контроля версий Git: создание локального репозитория, фиксация изменений, подключение удаленного репозитория и отправка изменений на GitHub.

## Ход работы

### 1. Создание локального репозитория

Для выполнения лабораторной работы использовалась операционная система Windows и Git Bash.

В рабочей директории проекта был создан локальный Git-репозиторий с помощью команды:

```bash
git init
```

Для проверки состояния репозитория была выполнена команда:

```bash
git status
```

### 2. Добавление файлов и создание коммита

Все файлы проекта были добавлены в индекс командой:

```bash
git add .
```

Перед созданием коммита были настроены имя пользователя и адрес электронной почты:

```bash
git config --global user.name "Егор Загребин"
git config --global user.email "your-email@example.com"
```

После этого был создан первый коммит:

```bash
git commit -m "Initial commit"
```

Для проверки истории коммитов была использована команда:

```bash
git log
```

### 3. Создание и подключение удаленного репозитория

На платформе GitHub был создан удаленный репозиторий.

Для обеспечения доступа к нему была выполнена настройка SSH-аутентификации: создан SSH-ключ и добавлен в настройки GitHub.

Затем удаленный репозиторий был подключен к локальному с помощью команды:

```bash
git remote add origin <URL-репозитория>
```

Для проверки подключения была выполнена команда:

```bash
git remote -v
```

### 4. Отправка локальных коммитов в удаленный репозиторий

Для отправки локального коммита на GitHub была выполнена команда:

```bash
git push -u origin main
```

В результате локальный коммит был отправлен в удаленный репозиторий.

После загрузки была проверена страница репозитория на GitHub, чтобы убедиться в успешной отправке файлов.
